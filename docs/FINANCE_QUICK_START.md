# Finance Module - Quick Start Guide

## 🚀 How to Use Percentage-Based Expense Allocation

### Step 1: Access Finance Module
1. Login to CRM
2. Click on **Finance** (💰) in the sidebar
3. Click **Projects** tab

### Step 2: Add New Project
1. Click **"+ Add Project"** button
2. Fill in basic details:
   - Project Number (e.g., "PRJ-001")
   - Project Name (e.g., "ABC Residential Complex")
   - Realized Fees (if any)
   - **Total Received Fees** (e.g., ₹1,00,000)

### Step 3: Set Expense Percentages
Now comes the magic! Under "💡 Expense Allocation (Percentage-based)" section:

#### Enter percentages for each expense category:
- **Profit Margin %**: Your desired profit (e.g., 30%)
- **Drawing %**: Design/drawing costs (e.g., 15%)
- **Documents %**: Documentation expenses (e.g., 5%)
- **Site Visit %**: Site visit costs (e.g., 10%)
- **Marketing & Misc %**: Marketing expenses (e.g., 8%)
- **Office Management %**: Office overhead (e.g., 12%)

#### Watch the amounts calculate automatically!
- As you type each percentage, the rupee amount updates instantly
- Formula: Amount = (Received Fees × Percentage) ÷ 100
- Example: ₹1,00,000 × 30% = ₹30,000

### Step 4: Review and Save
1. Check the calculated amounts (shown in green)
2. Total percentages can exceed 100% (system allows flexibility)
3. You can manually override amounts if needed
4. Select project status (Active/Completed/On Hold/Cancelled)
5. Click **"Save"** button

### Step 5: View Results
- Project appears in the table with net profit
- Green amount = Profit
- Red amount = Loss
- Click edit icon (✏️) to modify
- Click delete icon (🗑️) to remove

## 💡 Pro Tips

### Tip 1: Change Percentages Anytime
- Edit an existing project
- Change any percentage value
- Watch all amounts recalculate instantly
- No need to manually calculate rupees!

### Tip 2: Adjust Received Fees
- If you update Total Received Fees
- All expense amounts automatically recalculate
- Percentages remain the same
- Perfect for fee revisions!

### Tip 3: Use Decimal Percentages
- You can enter 12.5% or 33.33%
- System accepts up to 1 decimal place
- Useful for precise allocations

### Tip 4: Quick Allocation Templates
Save common percentage patterns:
- **Standard Project**: 30%, 15%, 5%, 10%, 8%, 12% (Total: 80%)
- **High Profit**: 50%, 10%, 5%, 5%, 5%, 5% (Total: 80%)
- **Detailed Work**: 20%, 25%, 10%, 15%, 10%, 10% (Total: 90%)

### Tip 5: Monitor Net Profit
- Net Profit = Received Fees - Total Expenses
- Green value = Profitable project
- Red value = Loss-making project
- Aim for 20-30% net profit margin

## ⚠️ Common Mistakes to Avoid

❌ **Mistake 1**: Forgetting to enter Total Received Fees first
✅ **Solution**: Always enter Received Fees before percentages

❌ **Mistake 2**: Percentages totaling over 100% without realizing
✅ **Solution**: Keep mental note or calculator for total percentage

❌ **Mistake 3**: Manually entering amounts instead of percentages
✅ **Solution**: Use percentage inputs (left column) for auto-calculation

❌ **Mistake 4**: Not updating percentages when fees change
✅ **Solution**: Edit project and system will auto-recalculate

❌ **Mistake 5**: Ignoring negative net profit warnings
✅ **Solution**: Reduce expense percentages or increase fees

## 🔢 Formula Cheat Sheet

```
Amount Calculation:
Amount = (Total Received Fees × Percentage) ÷ 100

Total Expenses:
Total = Profit Margin + Drawing + Documents + 
        Site Visit + Marketing & Misc + Office Management

Net Profit:
Net Profit = Total Received Fees - Total Expenses

Profit Margin %:
(Net Profit ÷ Total Received Fees) × 100

Break-even Point:
Total Expenses = Total Received Fees (Net Profit = 0)
```

## 🆘 Troubleshooting

**Issue**: Amounts not calculating
**Solution**: Check that Total Received Fees is entered first

**Issue**: Calculation seems wrong
**Solution**: Verify percentage value and received fees amount

**Issue**: Can't save negative percentages
**Solution**: Percentages must be 0-100% (validation prevents negative)

**Issue**: Decimal not working
**Solution**: Use dot (.) not comma (,) for decimals

**Issue**: Amount shows zero
**Solution**: Check if percentage is 0 or received fees is 0
